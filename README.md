# CodeAlpha Python Internship Tasks

This repository contains the Python projects completed as part of the CodeAlpha Python Programming Internship.

## Projects

### Task 1 – Hangman Game
A command-line Hangman game where players guess letters to reveal a randomly selected word.

### Task 2 – File Organizer
A Python application that automatically organizes files into folders based on their file extensions.

### Task 3 – Rule-Based Chatbot
A simple chatbot that responds to predefined user inputs using rule-based logic.

## Technologies Used

- Python
- OS Module
- Shutil Module
- Random Module
- Datetime Module

## Getting Started

```bash
git clone https://github.com/j1shii/codealpha_tasks.git
cd codealpha_tasks
```

Navigate to the desired project folder and run the corresponding Python file.
