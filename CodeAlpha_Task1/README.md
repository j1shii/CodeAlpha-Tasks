# 🎮 Hangman Game

A simple command-line Hangman game built using Python. The player guesses letters to reveal a randomly selected word before running out of attempts.

## Features

- Random word selection
- Letter-by-letter guessing
- Input validation
- Tracks incorrect guesses
- Replay option

## Technologies Used

- Python
- Random Module

## How to Run

```bash
git clone https://github.com/j1shii/CodeAlpha_task1.git
cd CodeAlpha_Hangman
python hangman.py
```
